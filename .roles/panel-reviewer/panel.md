# Education Access Peer Panel (illustrative)

Archetype peer reviewers for SLATE research outputs — distinct from the parliament (adversarial design review) and the editorial gate (form review). Each is an archetype, not a named person.

| ID | Reviewer archetype | Expertise |
|---|---|---|
| R-P1 | Education-system planner | School networks, attendance boundaries, feeder patterns, access planning |
| R-P2 | Network scientist | Feeder/transfer/articulation topology, graph algorithms, resilience |
| R-P3 | Education economist | Funding formulas, benefit-cost, affordability, labor and governance markets |
| R-P4 | Operations / education-services researcher | Enrollment flow, capacity, workforce, seat access, surge |
| R-P5 | Outcomes / equity scholar | Segregation, opportunity gaps, attainment, mobility, community outcomes |

Assignment guide:

- Topology / resilience method → R-P2, R-P4
- Capacity / wait time / enrollment operations → R-P4, R-P1
- Funding economics / governance / benefit-cost → R-P3
- Equity / shortage areas / outcomes and mobility → R-P5, R-P1
- Tier/SLA + multi-scale methodology → R-P1, R-P4
